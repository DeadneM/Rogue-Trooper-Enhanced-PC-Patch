# Rogue Trooper Enhanced PC Patch V64

First public GitHub release of the current validated stable build.

## Highlights

- 4K and ultrawide support
- Dynamic Hor+ field of view
- Conditional borderless mode with native fallback
- Multi-aspect HUD and UI fixes
- Alt-Tab and native Alt+F4 fixes
- Reticle and sniper scope corrections
- Font and menu scaling fixes
- Corrected floating HUD markers
- Encyclopedia image layout fix

## Installation

1. Download `Rogue_Trooper_Enhanced_PC_Patch_V64.zip`.
2. Extract `RogueTrooper_Patcher_V64.exe` next to the original `RogueTrooper.exe`.
3. Run the patcher.
4. Keep the generated `RogueTrooper.exe.Backup`.

The patcher verifies the exact supported retail executable before making any change and verifies the rebuilt V64 executable before installation.
